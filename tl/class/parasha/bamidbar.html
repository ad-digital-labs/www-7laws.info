Bamidbar — Numbers

Apatnapung taon sa ilang — ang sensus, ang mga paglalakbay, at ang mga pagsubok ng isang bansang hinuhubog.

Bamidbar (בְּמִדְבַּר), na nangangahulugang "Sa ilang," ay ang ikaapat na aklat ng Torah. Sinasaklaw nito ang apatnapung taon ng paglalakad ng Israel sa disyerto — isang panahon ng pagsubok, paghihimagsik, banal na parusa, at muling pananampalataya. Kabilang dito ang sensus ng mga tribo, ang kaayusan ng kampo, at maraming mga kaganapan na nagpapakita ng pakikibaka ng tao na magtiwala sa Diyos.

Para sa mga Noahide, ang Bamidbar ay naglalarawan ng mga kahihinatnan ng moral na kabiguan at ng kapangyarihan ng pagsisisi. Ang mga kwento ng paghihimagsik ni Korach, ang hula ni Balaam, at ang katapatan ni Pinchas ay nag-aalok ng walang hanggang aral tungkol sa katarungan, kababaang-loob, at kalikasan ng banal na probidensya.

Mga Lingguhang Bahagi ng Bamidbar

  • Bamidbar — Ang sensus ng Israel, ang kaayusan ng kampo sa paligid ng Tabernakulo
  • Naso — Mga tungkulin ng mga Levita, ang Sotah, ang Nazirite, ang Pagpapala ng Saserdote
  • Behaalotecha — Ang menorah, ang ikalawang Paskuwa, ang mga reklamo ng tao, ang ketong ni Miriam
  • Shelach — Ang ulat ng mga espiya, ang hatol na apatnapung taon, ang mga batas ng challah at tzitzit
  • Korach — Ang paghihimagsik ni Korach laban kina Moises at Aaron, nilamon ng lupa ang mga rebelde
  • Chukat — Ang pulang bakang baka, ang kamatayan nina Miriam at Aaron, ang tanso na ahas
  • Balak — Inupahan ni Balak si Balaam para sumpain ang Israel; pinagpala niya sila sa halip
  • Pinchas — Ang sigasig ni Pinchas, ang ikalawang sensus, ang mga anak na babae ni Zelophehad, hinirang si Josue
  • Matot — Mga batas ng panata, ang digmaan laban sa Midian, ang mga tribo ng Ruben at Gad
  • Masei — Nakalista ang mga paglalakbay ng Israel, ang mga hangganan ng Lupain, mga lungsod ng kanlungan
