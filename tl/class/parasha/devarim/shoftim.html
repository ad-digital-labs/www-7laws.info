Shoftim · Deuteronomy 16:18–21:9

Parasha Shoftim

Mga batas ng mga hukom, mga hari, mga pari, mga propeta, digmaan, at mga lungsod ng kanlungan — ang mga pundasyon ng isang makatarungang lipunan.

Pangkalahatang-ideya

Ang Parasha Shoftim ang komprehensibong blueprint ng Torah para sa isang makatarungang lipunan. Sinasaklaw nito ang paghirang ng mga hukom, ang mga batas ng paghahari, ang papel ng mga pari at Levita, ang pamantayan para sa tunay na propesiya, ang mga batas ng digmaan, at ang mga lungsod ng kanlungan.

Ang Kwento

Inutusan ni Moises: "Humirang ng mga hukom at opisyal sa lahat ng iyong mga pintuan... Katarungan, katarungan ang iyong hahanapin." Ang mga batas ng isang hari ay sumusunod: hindi siya dapat mag-ipon ng napakaraming kabayo, asawa, o ginto, at dapat sumulat ng sariling Torah scroll at basahin ito sa buong buhay niya. Ang pamantayan para sa isang tunay na propeta: ang kanyang mga salita ay dapat matupad, at hindi siya dapat mag-akay ng mga tao sa idolatriya. Mga batas ng digmaan: mag-alok ng kapayapaan bago umatake, huwag sirain ang mga puno ng prutas. Ang hindi nalutas na ritwal ng pagpatay — ang eglah arufah — ay nagsasara ng parasha: kapag natagpuan ang isang bangkay sa pagitan ng mga lungsod, ang mga matatanda ng pinakamalapit na lungsod ay dapat ipahayag ang kanilang inosensya at manalangin para sa pagbabayad-sala.

Kahalagahan para sa mga Noahide

"Katarungan, katarungan ang iyong hahanapin" — ang dobleng diin sa katarungan ay ang pinaka-direktang pahayag ng Torah ng obligasyon ng Noahide na magtatag ng mga hukuman. Ang mga batas ng paghahari ay nagtuturo na walang tao na pinuno ang nasa itaas ng batas — kahit ang hari ay dapat sumuko sa Torah. Ang pamantayan para sa tunay na propesiya ay nagpoprotekta laban sa mga huwad na relihiyosong pinuno na sinasamantala ang kanilang mga tagasunod.

"Katarungan, katarungan ang iyong hahanapin, upang mabuhay ka at maangkin ang lupain na ibinibigay sa iyo ng Panginoon mong Diyos." — Deuteronomy 16:20
